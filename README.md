# Aura for Mac

Downloads and updates for [Aura](https://aura.build)'s Mac app.

**[Download Aura for Mac](https://v2.aura.build/download)**, or get the newest
`Aura-universal.dmg` (every Mac) or `Aura-arm64.dmg` (Apple silicon) under
[Releases](https://github.com/MengTo/aura-releases/releases/latest).
It runs on macOS 13 or later, on Apple silicon and Intel Macs, and keeps
itself up to date from the releases here.

This repository holds only the signed, notarized releases; there's no code
in it.
